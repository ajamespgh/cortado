# Historical documentation

This directory preserves records from Cortado's browser/Node prototype before
the product-direction change. They are useful evidence of prior experiments,
implementation, and contracts, but are not current commitments unless a later
accepted foundation document, requirement, or decision explicitly adopts them.

## Contents

- [Prototype records](./prototype/README.md)

Current product direction, decisions, and open questions live in
[`docs/foundation/`](../foundation/README.md). New accepted behavioral
requirements and architectural decisions belong in `docs/requirements/` and
`docs/decisions/`, respectively.
